# LexMonitor

Sistema web de monitorización y gestión de procesos judiciales para abogados en Colombia.

## v0.1
Esqueleto inicial. El monitor de Rama Judicial aún no está conectado.

## Stack
Next.js + TypeScript + Tailwind CSS + Prisma + PostgreSQL.

## Principios
- GitHub contiene código/documentación, no expedientes reales.
- Las fuentes judiciales se integrarán mediante adaptadores aislados.
- Una consulta fallida no equivale a ausencia de actuaciones.
- Los secretos nunca se almacenan en GitHub.
